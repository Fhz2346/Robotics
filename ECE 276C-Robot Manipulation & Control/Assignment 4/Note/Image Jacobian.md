
| Let       | $\mathbf{u}$                                   | $\begin{bmatrix}u\\v\end{bmatrix}$                                                                                                                                                                                                                                                                                                                         |
| --------- | ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Let       | ${}^c\mathbf{p}_o$                             | $\begin{bmatrix}x&y&z\end{bmatrix}^\top$                                                                                                                                                                                                                                                                                                                   |
| then      | ${}^c\mathbf{v}_o$                             | $\begin{bmatrix}\dot{x}&\dot{y}&\dot{z}\end{bmatrix}^\top$                                                                                                                                                                                                                                                                                                 |
| Given     | $\begin{bmatrix}u\\v\end{bmatrix}$             | $\begin{bmatrix}\frac{fx}{z}+o_x\\\frac{fy}{z}+o_y\end{bmatrix}$                                                                                                                                                                                                                                                                                           |
|           | $\begin{bmatrix}\dot{u}\\\dot{v}\end{bmatrix}$ | $\begin{bmatrix}\frac{f\dot{x}}{z}-\frac{fx\dot{z}}{z^2}\\\frac{f\dot{y}}{z}-\frac{fy}{z^2}\end{bmatrix}=\begin{bmatrix}\frac{f\dot{x}}{z}-\frac{u\dot{z}}{z}\\\frac{f\dot{x}}{z}-\frac{v\dot{z}}{z}\end{bmatrix}=\begin{bmatrix}\frac{f}{z}&0&-\frac{u}{z}\\0&\frac{f}{z}&-\frac{v}{z}\end{bmatrix}\begin{bmatrix}\dot{x}\\\dot{y}\\\dot{z}\end{bmatrix}$ |
| **Intm1** | $\dot{\mathbf{u}}$                             | $\begin{bmatrix}\frac{f}{z}&0&-\frac{u}{z}\\0&\frac{f}{z}&-\frac{v}{z}\end{bmatrix}{}^c\mathbf{v}_o$                                                                                                                                                                                                                                                       |
| Let       | ${}^w\mathbf{v}_c$                             | $\begin{bmatrix}\dot{x}_c&\dot{y}_c&\dot{z}_c\end{bmatrix}^\top$                                                                                                                                                                                                                                                                                           |
| Let       | ${}^w\boldsymbol{\omega}_c$                    | $\begin{bmatrix}\omega_{x,c}&\omega_{y,c}&\omega_{z,c}\end{bmatrix}^\top$                                                                                                                                                                                                                                                                                  |
|           | ${}^w\mathbf{p}_o$                             | ${}^w\mathbf{p}_c+{}^w\mathrm{R}_c{}^c\mathbf{p}_{o}$                                                                                                                                                                                                                                                                                                      |
|           | ${}^w\mathbf{v}_o$                             | ${}^w\dot{\mathbf{p}}_c+{}^w\boldsymbol{\omega}_c\times({}^w\mathrm{R}_c{}^c\mathbf{p}_{o})+{}^w\mathrm{R}_c{}^c\dot{\mathbf{p}}_{o}$                                                                                                                                                                                                                      |
| Assume    | ${}^w\mathbf{v}_o$                             | $\mathbf{0}$                                                                                                                                                                                                                                                                                                                                               |
|           |                                                | $\mathbf{0}={}^w\dot{\mathbf{p}}_c+{}^w\boldsymbol{\omega}_c\times({}^w\mathrm{R}_c{}^c\mathbf{p}_{o})+{}^w\mathrm{R}_c{}^c\dot{\mathbf{p}}_{o}$                                                                                                                                                                                                           |
|           | ${}^c\mathbf{v}_o$                             | $-^c\mathbf{v}_c-{}^c\boldsymbol{\omega}_c\times{}^c\mathbf{p}_{o}$                                                                                                                                                                                                                                                                                        |
| **Intm2** |                                                | $\begin{bmatrix}-\mathrm{I}&[{}^c\mathbf{p}_{o}]_\times\end{bmatrix}\begin{bmatrix}^c\mathbf{v}_c\\^c\boldsymbol{\omega}_c\end{bmatrix}$                                                                                                                                                                                                                   |
|           | $\dot{\mathbf{u}}$                             | $\begin{bmatrix}\frac{f}{z}&0&-\frac{u}{z}\\0&\frac{f}{z}&-\frac{v}{z}\end{bmatrix}\begin{bmatrix}-\mathrm{I}&[{}^c\mathbf{p}_{o}]_\times\end{bmatrix}\begin{bmatrix}^c\mathbf{v}_c\\^c\boldsymbol{\omega}_c\end{bmatrix}$                                                                                                                                 |
|           |                                                | $\begin{bmatrix}\frac{f}{z}&0&-\frac{u}{z}\\0&\frac{f}{z}&-\frac{v}{z}\end{bmatrix}\begin{bmatrix}-1&0&0&0&-z&y\\0&-1&0&z&0&-x\\0&0&-1&-y&x&0\end{bmatrix}\begin{bmatrix}{}^c\mathbf{v}_c\\{}^c\boldsymbol{\omega}_c\end{bmatrix}$                                                                                                                         |
| **Conc**  | $\mathrm{L}$                                   | $\begin{bmatrix}\frac{-f}{z}&0&\frac{u}{z}&\frac{uv}{f}&-\left(f+\frac{u^2}{f}\right)&v\\0&\frac{-f}{z}&\frac{v}{z}&\left(f+\frac{v^2}{f}\right)&-\frac{uv}{f}&-u\end{bmatrix}$                                                                                                                                                                            |
| called    |                                                | **Image Jacobian**                                                                                                                                                                                                                                                                                                                                         |
