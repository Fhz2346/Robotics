
| 1   | Sample the space                                                                                                                                                                                                              |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
|     | Each iteration selects the goal directly with 15% probability; <br>otherwise, it random **sample** at Cspace                                                                                                                  |
| 2   | Extend the tree                                                                                                                                                                                                               |
|     | The planner finds the existing tree node nearest to the **sample** and moves up to 15° toward it to create a **new node**.                                                                                                    |
| 3   | Check for collisions                                                                                                                                                                                                          |
|     | The new node and the connecting edge must in Cspace. <br>The connecting edge is checked by sampling along it at roughly 3° intervals.                                                                                         |
| 4   | Choose a low-cost connection                                                                                                                                                                                                  |
|     | Among nearby tree nodes, the planner chooses a valid parent that gives the new node the lowest accumulated path cost from the start.                                                                                          |
| 5   | Rewire nearby nodes.                                                                                                                                                                                                          |
|     | If connecting a nearby node through the new node creates a shorter valid path, the planner updates that node’s parent. This lets RRT* improve its path as it explores.                                                        |
| 6   | Try to connect to the goal.                                                                                                                                                                                                   |
|     | When a new node is close enough to the goal and the connecting edge is valid, the planner records a feasible path. <br>It continues for at least 500 more iterations after finding the first path, looking for a shorter one. |
